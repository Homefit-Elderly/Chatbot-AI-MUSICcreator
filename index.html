Features

Built for people who hear it before they can play it.

✍︎

Prompt-native

Plain language in, music out. "Nostalgic but not sad, 90 bpm, brushed drums" is a valid input.

🎛

Stems, not just mixes

Every render ships separated tracks — drums, bass, keys, lead — ready for your DAW.

♪

MIDI export

Get the notes, not only the audio. Re-voice, re-tempo and re-arrange anything.

↻

Iterative edits

"Same idea, warmer, drop the drums after bar 16." Muse keeps the motif and changes the rest.

⌘

CLI & Python API

One command locally, or three lines in a notebook. Batch a hundred variations overnight.

⚖︎

Clean training data

Trained on licensed and public-domain recordings. Output is yours, commercially usable.

🅴

Unfiltered prompts

Swearing, blunt phrasing and explicit lyrics all go through. Muse reads them as attitude and energy instead of refusing the prompt — and tags the render explicit so you can filter downstream if you need to.

↯

Attitude mapping

Harsh language pushes tempo up, harmony minor, and the mix dirtier — the same way a producer would read the room.

How it works

From a phrase to a finished arrangement.

Read the intent

A language encoder maps your phrase to a musical intent vector: mood, energy, era, instrumentation, tempo range and harmonic colour.

Compose the structure

A symbolic model writes the piece as notes first — key, chord movement, motif, form — so the result has an actual shape instead of a texture. Output is .mid.

Render and mix

A neural synthesizer performs the score with the chosen instruments, then a mix stage balances and masters it. You get .wav, stems and the MIDI.

Get started

Running locally takes about a minute.

licenseMIT python3.10+ buildpassing stars4.2k 
# clone and install
git clone https://github.com/your-username/muse-ai.git
cd muse-ai
pip install -e .

# generate from a phrase
muse "a rainy Tuesday in Lisbon, slow piano, tape hiss" \
  --length 45s --stems --out ./renders

# prompts are never filtered; --tag-explicit only labels the output
muse "fuck this week, loud guitars, no chorus" --tag-explicit

# or from Python
from muse import Muse
Muse().compose("sunrise over an empty motorway").save("drive.wav")
